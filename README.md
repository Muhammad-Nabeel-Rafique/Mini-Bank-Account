# Digiskills Bank Limited - CLI Banking System

A secure, Object-Oriented Command Line Interface (CLI) banking application built with Python. This program allows users to create password-protected bank accounts, manage funds, check balances, and automatically generate detailed text-file transaction receipts.

---

## 🌟 Key Features

- **Account Creation**: Interactive account setup with auto-generated Customer IDs and Account Numbers.
- **Strict Password Validation**: Enforces strong passwords (minimum 8 characters with upper/lowercase letters, digits, and special characters).
- **Secure Authentication**: Prevents unauthorized access with strict password matching.
- **Transaction Processing**: Safe handling of deposits and withdrawals with real-time balance checks and input validation.
- **Automated Receipt Generation**: Automatically exports detailed text receipts (with timestamps) into a designated `receipts/` directory upon every successful transaction.
- **Interactive CLI Menus**: Multi-level console menus for seamlessly navigating system operations and individual user sessions.
